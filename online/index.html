COMO USAR O MODO ONLINE

No navegador (este hub)

  1. Entre com um apelido.
  2. Crie uma sala (mapa, modo, nº de jogadores) ou entre com um código de convite.
  3. Convide amigos pelo botão COPIAR CONVITE — o link abre esta página e entra direto na sala.
  4. Marque PRONTO; quando todos estiverem prontos, o anfitrião inicia a partida.
  5. Use SIMULAR PARTIDA (DEMO) para ver a sincronização em tempo real (abra outra aba/janela para conferir).

No jogo (BO1Zombies.exe)

  1. Compile o jogo (CMake + Visual Studio, ver README da raiz).
  2. Inicie com +set online_name "SeuNick" +set fs_mods online (e opcionalmente +set online_room CODIGO).
  3. O mod mods/online conecta ao mesmo Firebase: presença, chat, rodadas, abates e baixas aparecem aqui no hub em tempo real.

Configuração do Firebase

Este hub usa o projeto kaka-ca0ff (Realtime Database). Se os botões de escrita falharem, publique as regras de online/database.rules.json no console do Firebase e/ou ative a Autenticação anônima.
